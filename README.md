# SP MART - Electronics Shopping Website

## Project structure

- `index.html` — main website page
- `style.css` — all website styling and responsive layout
- `script.js` — products, login, search, categories, cart, wishlist, checkout and demo payment flow
- `assets/` — folder reserved for local images/assets

## Run

Open `index.html` in a browser.

The product/background images currently use external Unsplash URLs, so an internet connection is needed for those images to load.

## Demo login

Any non-empty email/mobile and password will log in because this is a front-end demo. No real authentication or payment is implemented.
